# Vibe CRM Kanban

Bem-vindo à documentação oficial do **Vibe CRM Kanban**. Este projeto é um sistema integrado de gestão (SGI) focado em autoescolas e despachantes, combinando CRM (Gestão de Relacionamento), ERP (Gestão Empresarial) e Financeiro.

## 🚀 Visão Geral do Sistema

O sistema é construído com tecnologias modernas para garantir performance e escalabilidade:

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Shadcn/UI.
- **Backend**: Supabase (PostgreSQL, Auth, Edge Functions).
